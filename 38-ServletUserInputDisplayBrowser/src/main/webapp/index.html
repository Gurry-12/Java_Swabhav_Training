Servlet Assignment Dashboard

Java Web Application - Multiple Servlet Endpoints

Available Servlets

  1. 1. Form Submission
    Accepts Full Name and Age
    Mapping: /submit (POST)
    Open Submission Form

  2. 2. Student Registration
    Register a new student with roll number, name and course
    Go to Student Form

  3. 3. Employee Management
    Add or view employee information
    Go to Employee Form

  4. 4. Product Catalog
    Add and display product details
    Go to Product Form

  5. 5. Login Authentication
    Simple user login validation
    Go to Login Page

Note: Create the respective HTML forms and Servlets as per the mappings.
