# Java Basics - Tricky Challenges 🚀

Welcome to the challenge section! These problems are designed to test and deepen your understanding of Java fundamentals.

## 📚 Challenge Structure

### Challenge 1: Tricky Operators
**Focus:** Operator precedence, increment/decrement, type promotion
- Tests your understanding of `++`, `--`, operator precedence
- Predict outputs before running!

### Challenge 2: Type Casting Puzzles
**Focus:** Implicit/explicit casting, data loss, overflow
- Understand how Java handles type conversions
- Learn about byte overflow and precision loss

### Challenge 3: Control Flow Traps
**Focus:** if-else, switch, logical operators
- Common pitfalls in conditional statements
- Switch fall-through behavior
- Short-circuit evaluation

### Challenge 4: String Mysteries
**Focus:** String pool, immutability, comparison
- `==` vs `.equals()`
- String pool and `intern()`
- String immutability gotchas

### Challenge 5: Function Puzzles
**Focus:** Method overloading, pass-by-value, recursion
- How Java passes arguments
- Method resolution rules
- Recursion tracing

### Challenge 6: Practical Problems
**Focus:** Implementation challenges
- Reverse integers
- Palindrome checking
- Armstrong numbers
- **YOU IMPLEMENT THESE!**

### Challenge 7: Logic Building
**Focus:** Algorithmic thinking
- GCD calculation
- Prime number checking
- Fibonacci sequence
- Pattern printing
- Number system conversion
- **YOU IMPLEMENT THESE!**

## 🎯 How to Use These Challenges

1. **For Challenges 1-5 (Prediction Problems):**
   - Read each question carefully
   - Write your prediction as a comment
   - Run the code
   - If wrong, understand WHY
   - This builds intuition!

2. **For Challenges 6-7 (Implementation Problems):**
   - Read the problem statement
   - Try to solve WITHOUT looking at hints
   - If stuck, read the hint
   - Test with provided test cases
   - Try edge cases!

## 💡 Learning Tips

- **Don't rush!** Take time to understand each concept
- **Predict first, run later** - this builds mental models
- **Debug step-by-step** - use print statements to trace execution
- **Try variations** - modify the code and see what happens
- **Explain to yourself** - if you can explain it, you understand it
